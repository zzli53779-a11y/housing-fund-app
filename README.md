## 项目简介

基于 **Uni-app** 实现的「全国住房公积金」风格移动端界面，覆盖首页服务入口、个人账户、缴存明细与历史查询等常见业务页面。

技术栈：**Uni-app · Vue · 自定义导航栏 · TabBar**

---

## 功能亮点

| 模块 | 说明 |
|------|------|
| 首页服务 | 余额卡片、热门服务入口、城市服务、轮播 Banner |
| 我的账户 | 个人账户状态、余额、账号与中心信息 |
| 账户详情 | 个人/单位缴存额、缴存比例等明细 |
| 缴存历史 | 按月查询缴存记录 |
